## 🛠 Ключевые навыки в Power BI
* **Power Query (ETL):** Импорт, очистка и трансформация данных из разрозненных источников.
* **Моделирование данных:** Построение связей между таблицами (схема «Звезда» / «Снежинка»).
* **DAX:** Написание вычисляемых мер, столбцов, работа с контекстом фильтрации и функциями Time Intelligence.
* **Визуализация:** Интерактивные отчёты, настройка срезов, кросс-фильтрация, KPI-карточки и кастомная детализация.
